# Source provenance

The initial GitHub repository held an earlier three-strategy hardware snapshot. Its history remains in Git, and its exact files are preserved in the companion research repository under `history/github_original_main/`.

The release source here was copied from the author's saved `low comm algorithms expirement` directory. That directory includes the processed workbook `Trials for message drops_final copy.xlsx`. Its nine condition sheets supplied the 540 robot records and 135 system records in this repository. The first 15 saved scenarios supplied `published_scenarios.csv`. The research repository retains the original workbook, additional scenarios, development code, and a checksum inventory of raw logs retained locally.

The code files are archived experiment snapshots. Their current configuration values are recorded in the files; the README explains how to set the intended robot ID and loss condition for a hardware run. The table reproduction script uses the saved processed measurements without changing historical source files.
